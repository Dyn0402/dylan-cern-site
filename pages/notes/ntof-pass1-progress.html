Details

The registry is built from the run titles and run configs, so it carries latency, samples, HV, noise era and access epoch per sub-run. The noise floor doubled on 23 July (RdClk_Div 6→4): run_68 sits inside the bracket and is excluded or checked directly.

The same code path as the bench and SPS pass is used, with no WFT_* switches; the ledger must prove every row ran on the archived code and that every output exists (a few EOS FUSE I/O flakes are retried twice).

Details

Q7 compares xy_pairing select gate vs cost and split_corrob off vs charge, scored on overlays of real beam single tracks (A 695, C 783 overlays, steep donors included). Accepted ghosts per overlay fall 0.24 → 0.11; the shallow member of a shallow+steep pair is right 36 → 71 / 68 % of the time.

Nothing else moves: single tracks, the A–C line (1,647 → 1,645 lines, same residuals) and the capsule-pointing excess (A 1463 ± 69 → 1446, C 1206 ± 61 → 1201). With cost + charge the in-acceptance efficiency is flat in tan_max, tracks above 0.6 carry no pointing excess, and tan_max 1.0 or a column window only adds line mis-fits and +30–60 % CPU. tan_max stays 0.6 raw. Applied in ntof_bundle.py.

5

Details

v is the timing v = gap / column duration, never a waveform χ²(v). A–C line muons: A 38.4 ± 0.7 (x) / 38.9 ± 0.8 (y), C 27.7 ± 0.7 / 28.6 ± 0.7 µm/ns, in agreement with is2's geometric in-situ v (38.0 / 28.7) by an independent route.

Model checks: the template holds (A, C within 0.02 of peak; systematic 0.1° / 0.15 mm); the saturation rail stays at 3550 (a per-sample rail is the real fix, proposed in model_checks/FINDINGS.md, not applied). The channel layer is neutral on the A–C line (15 of 1,909 lines lost) and on beam removes 4.4 % of A's tracks, almost all non-pointing.

What this does not rule out

• Chamber D on beam: a ~360 ns oscillation on 82–90 % of triggers means its beam v and angles are not measurable. A hum flag or sinusoid subtraction is untested.

• Chamber B: positions only; no angle.

• Chamber C: its angle scale moves ~1.5 % between sub-runs; a per-sub-run v is open.

• Q7 and the pin were scored on A–C cosmics and run_145 overlays; other beam runs are checked only at N-G1.
